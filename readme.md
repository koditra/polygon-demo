This is a 3D interactive website built with HTML, CSS, and JavaScript. It showcases my planned projects and tracks my progress toward building them on the M5Stack Cardputer.

## Running Locally
Clone the repository and open index.html in your browser, or use a local development server.

# Planned Projects

The goal is to turn the Cardputer into a mini portable computer with useful tools, games, hardware integrations, and more.
